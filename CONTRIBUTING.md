# Contributing to Prepdesk

Open an issue for a bug or feature and include reproduction steps where possible. For Android issues, include the Prepdesk version, Android version, and relevant permission state. Remove private message text and identifying data from logs.

Create a branch from `master` and open a pull request against it. Keep changes focused and describe how you verified them. Bluetooth changes benefit from a two-phone test with Wi-Fi and mobile data switched off. Use GitHub Actions for Flutter and Android builds.

The default branch is protected and requires a pull request. Maintainers merge the pull request after verification. For a release, tag the merged commit with the agreed version and confirm GitHub Actions published the APK, Play bundle, and checksums.
