# Prepdesk v1.2.1

- Start or open a Blend with the icon beside the star in a private conversation. Type `/spectate` to open shared progress or start a watch-only invitation.
- Active Blends and invitations sit under Conversations and People in PrepChat’s Network. Setup and progress use PrepChat’s sheets.
- Manage update times, sharing choices, and watch-only sessions from Blend settings between Spam Filter and Tor.
- Offline APK downloads and hotspot sharing use the signed Prepdesk release.
- GitHub Releases publishes the already-tested APKs and Play bundle from pre-prod.
